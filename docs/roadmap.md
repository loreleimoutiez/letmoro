## Next device checks

1. Install 0.1.3 as an update. Test Google and email account creation/sign-in, confirmation, recovery, session restoration and sign-out. Verify returning users keep their own local game and a second account cannot read it.

3. Start a fresh game through the temporary reset. Confirm older daily steps lengthen the starting path but the quest is `0 / required` until new steps after meeting/connection. Verify above-character text and below-character controls in portrait, landscape and larger text.

## Rules and reliability

- Finalize calendar/time-zone and late-correction policies before life penalties, recovery, rest or cadence challenges.
- Reconcile provider totals, foreground estimates and persistence across device reboot/background/offline conditions. Current maximum-overlap handling is conservative and not proof of every wearable combination.
- Define mode switching, pause boundaries, rescue activation/failure, goal changes and reserve rebalance. Do not invent finalized policies or equate missing data with zero.
- Validate fresh installation and physical encrypted-session failure handling. Remove temporary reset and local download access before public distribution.

## Narrative and production

- Write the full act/cast structure, first act and substantial refusal/private-life routes. Author letters, deliberate opening choices and consequences, return notes/witnesses and endings.
- Implement actual trait/mode mechanics after necessary health/calendar rules. Current settings are saved choices, not active life systems.
- Add account-owned cloud save policies and conflict handling only after defining privacy/data ownership. Account deletion/export and production email configuration remain production work.
- Review French/English accessibility, real-time local-hour presentation and expansion compatibility. Keep the current dark presentation until a new time-of-day design is agreed.
- Validate S23 + Fit3 integration on hardware before promising wearable latency/cadence.

The intended first public campaign remains complete and substantial across all continuing major routes. Counts and duration in the product specification remain planning targets.

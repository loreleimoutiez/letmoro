# Delivery roadmap

## Current milestone

Version 0.2.0 is a playable opening with authored correspondence and recurring inhabitants, not the full five-arc campaign. See [gameplay status](gameplay-status.md) and [handoff](handoff.md) for implemented behavior and verification. Source/docs commits and an internal APK are authorized; publication, push and a public license are not.

The Supabase save migration is deployed and verified. The ordinary HUD is restored; internal test/reset/replay UI and browser-preview captions are removed. The local ignored manuscript contains twenty new letters, seven conversations and thirty thoughts. Rest weekday scheduling follows the latest confirmed next-Monday/seven-day rule.

## Physical acceptance before enabling penalties

1. Update the S23 with the same application/signing identity; preserve progress. Verify Health Connect invitation/ready skip, denial/revocation, foreground movement, background/resume and unknown-data display.
2. Confirm actual closed-day history, literal zero versus missing values, fixed-zone midnight/DST ranges and late corrections. Keep VITE_LIFE_RULES=false until this works reliably. Test the user's Fit3/phone source combination; no cadence/latency promise.
3. Verify actual email/Google callbacks, encrypted-session restore, logout and account separation. Verify cloud upload then restoration on a second device, offline retry and an explicit concurrent-save conflict.
4. Play long routes on a phone; verify thought pacing, above-Moro reading, independent zoom and tiny compass in portrait/landscape and larger text. Track decision density rather than inflating duration only through travel.

## Next gameplay work

- Author the remaining first arc and all continuing major routes, then the other four arcs and personalized epilogue. Optional romance and political participation must not replace substantial private-life/refusal routes.
- Expand contextual consequences beyond the opening's trust/witness/report model, with authored scenes and recoverable relationships. Add discovered skill branches and real trait effects, preserving unknown nodes and avoiding automatic commitments.
- Design goal/mode switching, emergency-pause boundaries, account-wide rescue and archive-preserving reboot. Follow lives-and-reboot; user deferred these while implementing life/rest/recovery first. Never silently refresh rests/rescue through mode or account-local resets.
- Reconcile multi-day closed-app travel, old corrections and travel-zone overlap without duplicate credit. Preserve missing data as unknown. Compact replay and version content/save migrations before year-long scale.
- Meaningful spending/home/customization, archive export/deletion/retention and durable private-content backup. Private remote remains an owner decision; no manuscript is backed up by Git ignore.

## Public release gate

A substantial complete campaign across continuing major routes; physical health/auth/cloud validation; accessibility and account-data controls; production signing/update strategy; complete localized copy and honest documentation. An internal APK is a milestone, not the promised public release.
